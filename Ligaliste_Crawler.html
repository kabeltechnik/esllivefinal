Ligalisten-Crawler

Holt die Ligalisten-Kennzahlen fuer beliebig viele Standorte und Zeitraeume in EINE Excel-Mappe — ohne jede Abfrage einzeln von Hand einzustellen.

1. Hier einstellenStandorte, Zeitraum und Intervall waehlen, dann „Code erzeugen“.
2. KopierenAuf „Kopieren“ druecken.
3. In der Ligaliste einfuegenDort F12 druecken, in die Konsole einfuegen, Enter. Der Rest laeuft allein.

Konfiguration

Getrennt ist uebersichtlicher und schont den Server; zusammen ist schneller.
Jeder Zeitraum wird einzeln abgefragt und bekommt im Excel einen eigenen Block. Das Portal erwartet YYYYMMDD — die Umwandlung passiert automatisch.
Ein Name=Wert je Zeile. Wird ueber den mitgeschnittenen Original-Body gelegt. Die echten Parameternamen zeigt rc_lupe.js auf der Ligalisten-Seite an (Panel, Zeile anklicken).
Zu schnelle Abfragen quittiert das Portal mit HTTP 500. Der Code wiederholt jede Abfrage bis zu dreimal.

Code fuer die Konsole

Links einstellen und auf „Code erzeugen“ druecken.

Der erzeugte Code ist bewusst in eine IIFE gewickelt — er laesst sich
also beliebig oft in dieselbe Konsole einfuegen. Snippets mit
"const ... = await ..." auf oberster Ebene brechen beim zweiten
Einfuegen mit "Identifier has already been declared" ab.

Dass die Konsole nach dem Einfuegen "undefined" anzeigt, ist normal:
das ist der Rueckgabewert, kein Fehler. Ob es laeuft, steht in den
Meldungen darunter und im Fortschrittsfenster unten rechts.
