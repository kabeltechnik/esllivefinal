WCA-Autopilot ESL + CCS mit einem Lesezeichen-Klick

1. Installation (einmalig, 10 Sekunden)

Diesen roten Knopf mit der Maus in die Lesezeichenleiste ziehen (Leiste einblenden: Strg+Umschalt+B):

WCA-Autopilot

Alternativ: Rechtsklick auf die Lesezeichenleiste → "Seite hinzufuegen" → Name WCA-Autopilot, als URL den kompletten Code aus dem Feld unten einfuegen.

2. Taeglicher Ablauf

Wo du bistWas der Klick auf das Lesezeichen tut
Beliebige Seite (Start)Oeffnet CCS in einem neuen Tab und laedt im aktuellen Tab die ESL-Login-Seite.
ESL-Login-SeiteWartet auf Chrome-Autofill und schickt den Login ab.
ESL nach dem LoginKlickt automatisch: Vodafone Kabel → Projektergebnisse → Export Projektergebnisse — und startet das Live-Arena-Dashboard.
Microsoft-Anmeldung (CCS-Tab)Klickt "Weiter"/"Anmelden" sobald Autofill da ist, wartet still auf die Authenticator-Freigabe, beantwortet "Angemeldet bleiben?".
CCS nach dem LoginNavigiert direkt zur Ligaliste.
LigalisteStartet den KPI-Crawler — die Qualitaetsdaten funken automatisch ins Dashboard.

Faustregel: Nach jedem vollen Seitenwechsel einmal aufs Lesezeichen klicken. Innerhalb einer Seite (Menue-Klicks, Microsoft-Masken) arbeitet der Autopilot selbststaendig weiter. Das Status-Banner unten rechts zeigt immer, was gerade passiert.

3. Erster Lauf: Script-Dateien hinterlegen

Beim allerersten Start fragt der Autopilot einmalig nach den Script-Dateien (Datei-Dialog):

  1. Im ESL: esl_live_arena_v22.js auswaehlen
  2. Auf der Ligaliste: kpi_crawler.js auswaehlen

Die Dateien werden im Browser (localStorage der jeweiligen Seite) gespeichert — danach nie wieder noetig. Nach einem Script-Update: Lesezeichen auf der laufenden Seite erneut klicken → Frage "neu einlesen?" mit OK bestaetigen.

Hinweis: Falls die Ligaliste meldet "Kein Dashboard-Fenster erreichbar", einfach im Dashboard oben den KPI-Knopf druecken (oeffnet die eingeloggte Ligaliste mit Direktverbindung) und dort das Lesezeichen einmal klicken.

4. Bookmarklet-Code (Roh-String)

Sicherheit: Der Autopilot tippt keine Passwoerter und speichert keine Zugangsdaten — er wartet ausschliesslich auf das Chrome-eigene Autofill und klickt dann die vorhandenen Buttons. Das Portal-DOM wird nicht veraendert, nur ergaenzt (Status-Banner + Dashboard-Overlay).
